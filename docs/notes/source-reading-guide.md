## How we handle questions while reading

- Before expanding a question, check both later source passages and our existing learning notes.
- **Needed now:** explain prerequisites and flag misleading simplifications promptly, even if a later passage revises them.
- **Expanded later:** identify the destination and give enough context to continue. Offer to revisit it there or jump ahead; do not automatically defer a question the user wants to explore now.
- **Not adequately answered in the source:** record the gap and investigate it when appropriate. Mentioning a topic later is not the same as answering the question.
- Keep user reactions even if the text later addresses them. When revisiting, focus on what is new, changed, unclear, or unsupported rather than repeating a full explanation.
- An overview being understood does not complete the later deep dive. Source coverage, user understanding, and evidence checking are separate kinds of progress.

03 / Reading route

Start with a topic, then use the notes

The documents are self-contained, but they share a research vocabulary. A practical route is:

  1. Choose a pack. Open the research document for the topic you want to study.
  2. Read the argument first. Use the document’s contents rail and section anchors to follow the evidence and caveats.
  3. Use the deck as an introduction. The companion presentation gives a shorter route through the same material.
  4. Check the notes. The source audits and learning notebook record what was read, what remains uncertain, and what is only an engineering hypothesis.
No build step

The library is static HTML plus local CSS. Relative links keep the pages portable under the docs/ GitHub Pages root; external DOI and GitHub links require internet access.

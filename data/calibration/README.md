# Calibration data

- `contrastive.jsonl` — 864 rows, 32 per channel, coarse `0.0/0.5/1.0` targets, perspectives recorded, train/test split (675 train / 189 test).
- `mixed.jsonl` — 162 active-channel scenarios with 2–6 active channels, train/test split (120 train / 42 test).
- `negative_controls.jsonl` — 110 rows, all 27 channels explicitly `0.0`, train/test split (80 train / 30 test).
- `mixed_labeled.jsonl` — 110 rows, all 27 channels explicitly labeled, train/test split (80 train / 30 test).
- `rubric.md` — hand-crafted coarse anchors for the 27 channels.

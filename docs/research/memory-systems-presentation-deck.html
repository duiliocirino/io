01 · Memory systems

Memory is a lifecycle.

Encoding, retrieval, consolidation, and updating are different operations—not one storage lookup.

02 · The stability–plasticity problem

Fast episodes.
Slow structure.

  • Fast episodic

    Specific

    Sparse, orthogonal, one-shot encoding of a particular experience.

  • Slow semantic

    General

    Distributed, overlapping structure learned gradually across experiences.

  • Why split

    Interference

    Forcing shared weights to absorb a new episode can degrade older knowledge.

Complementary learning systems is a framework, not a literal list of two software modules or exact biological learning rates.

03 · Three functional tiers

Workspace, labile index, durable structure.

  • WM

    Active workspace

    Pointers to long-term nodes, transient maintenance, and control of access.

  • STM · labile

    Episodic index

    Fast, sparse episode record and quarantine buffer for novel or surprising content.

  • LTM

    Durable structure

    Semantic and procedural knowledge with distributed, overlapping representations.

“STM” here is a Short-Term Labile Episodic Store, not a generic short-term memory box. The tiers are functional distinctions, not sealed containers.

04 · Working memory

Point, don’t copy.

  • Activation

    Pointers

    Working memory makes existing long-term nodes available rather than duplicating them.

  • Maintenance

    Warm or active

    Some items persist; activity-silent maintenance is proposed and still debated.

  • Gating

    Input / output

    What enters the workspace and what is released are separate control decisions.

A context window plus controller is a candidate. A KV cache is runtime reuse, not a biological working-memory mechanism.

Pointer activation, activity-silent maintenance, and PBWM gating →04 / 12
05 · Episodic encoding

Index the episode.
Separate similar ones.

  • Index

    A light pointer

    The hippocampal account indexes co-active cortical features and nodes.

  • Separation

    Distinct codes

    Sparse, orthogonal representations keep near-duplicate experiences from interfering.

  • Salience

    Priority tag

    Novel, emotional, or high-value content is written quickly into the labile store.

Vector similarity alone can blur near-duplicates. Explicit episode IDs, timestamps, provenance, and separation policies matter.

Hippocampal indexing, pattern separation, and the episode-record problem →05 / 12
06 · Retrieval

A cue reactivates a pattern—not a recording.

  • Completion

    Fill the pattern

    A partial cue can reactivate the episode index and associated long-term nodes.

  • Context

    Match the cue

    Encoding specificity and current state affect which memory is retrieved.

  • Source

    Check provenance

    Observed, inferred, and generated content can be confused.

Top-k similarity is not pattern completion. Reconstruction should retain provenance and confidence.

Pattern completion, encoding specificity, and source monitoring →06 / 12
07 · Consolidation

Replay integrates.
It does not just move files.

  • Interleave

    Mix episodes

    New traces are replayed alongside older patterns and regularities.

  • Abstract

    Update structure

    Repeated experience can shape durable semantic or procedural knowledge.

  • Promote / clear

    Lifecycle

    After consolidation, the labile index can be archived or garbage-collected.

Sleep and rest can contribute, but consolidation is not only sleep. Synaptic homeostasis and memory consolidation are related but distinct.

Replay, sleep evidence, homeostasis, and retention limits →07 / 12
08 · Schema bypass

Fast-track consistency.
Quarantine surprise.

  • Consistent

    Fast assimilation

    Information that fits an existing schema can become durable with minimal quarantine.

  • Violating

    Slow restructuring

    Surprising or conflicting information is held in the labile store and replayed gradually.

The rat evidence does not establish a reliable LLM schema classifier. “Bypass” means bypassing slow consolidation, not bypassing validation.

Schema assimilation, evidence limits, and quarantine →08 / 12
09 · Generative replay

AB + BC → AC—then validate.

  • Recombine episodes. Recurrent interaction can link experiences through a shared item.
  • Create a synthetic insight. The combined relation AC was inferred, not directly observed.
  • Validate the link. Keep observed edges separate from inferred edges and record provenance.

REMERGE is a computational model of generalization. Vector similarity is not transitive, and a generated link can be false.

Generative replay, transitive inference, and validation →09 / 12
10 · Direct use and updating

Act from one episode.
Edit with prediction error.

  • Episodic control

    Direct lookup

    A labile episode can support a one-shot decision before a general rule is consolidated.

  • Reconsolidation

    Bounded update

    A prediction error can reopen a retrieved trace for a time-limited, versioned correction.

Neither is an unrestricted memory write. Direct lookup is not a general policy; reconsolidation is not a simple database edit.

Episodic control, reconsolidation, and the evidence boundaries →10 / 12
11 · Engineering candidates

Stores are not the whole system.

  • Hot index

    Redis candidate

    Fast recent episodes with TTL, explicit IDs, provenance, and promotion rules.

  • Durable records

    Vector DB + graph

    Persistent records and relations—not a structural connectome by themselves.

  • Parametric knowledge

    Weights / adapters

    Procedural and learned structure, distinct from a record store.

The active context/controller and the consolidation worker are also needed. Redis and vector databases are candidates, not identities.

A minimal loop, data contract, and unresolved choices →11 / 12
